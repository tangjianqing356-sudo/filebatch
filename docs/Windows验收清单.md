# Windows 真机验收清单

> 这份清单对应交付说明第十节的"下一步"。
> 目标：**把真机验收压缩成几条命令 + 一份肉眼核对**，结果能直接填进最终报告。
>
> 前置：Windows 10/11 x64，不需要管理员权限，不需要装 Python。

---

## 〇、先拿到包

两条路，选一条：

**A. 从 CI 拿（推荐）** —— 推一次 `main` 或手动触发 `构建与验证` 工作流，
在 Actions 页面下载 artifact `文件批量处理工具-Windows-x64`，解压。

**B. 本机构建** —— 装 [uv](https://astral.sh/uv)，然后：

```powershell
uv venv --python 3.12
uv pip install -r requirements-dev.txt --python .venv/Scripts/python.exe
.venv/Scripts/python.exe -m PyInstaller packaging/app.spec --distpath dist_app --workpath build --noconfirm --clean
```

产物在 `dist_app/FileBatchTool/FileBatchTool.exe`。

---

## 一、自动检查（四条命令，覆盖清单第 2、3、5、6、7 项）

在解压出来的目录里开 PowerShell：

```powershell
.\FileBatchTool.exe --env-report
```
```powershell
.\FileBatchTool.exe --selftest
```
```powershell
.\FileBatchTool.exe --acceptance
```
```powershell
.\FileBatchTool.exe --platform-check
```

**期望结果**

| 命令 | 期望 | 对应清单项 |
|---|---|---|
| `--env-report` | 打印系统/架构/Python/编码；**长路径探测结果记下来**（有没有开 LongPathsEnabled） | 5 |
| `--selftest` | `共 7 项，失败 0 项`，含 `6 个功能页 + 6 个 Excel 子页全部可创建` | 3 |
| `--acceptance` | `共 11 个功能，失败 0 个` | 3、4、8 |
| `--platform-check` | `共 11 项，失败 0 项` | 5、6、7 |

`--acceptance` 里的 `Excel 工具箱 · 格式统一` 一项已经覆盖了清单第 8 项的
绝大部分：默认保留字体/字号/对齐、多工作表不丢、数字类型不变、
图表/图片/条件格式/表格对象按验收样例核对。

`--platform-check` 覆盖：中文与空格路径、emoji 路径、长路径读写、
超限路径在预览阶段被拦下、源文件被占用、输出目录没有写权限、
输出目录=源目录、输出位置不存在、`.xlsm` 往返、格式统一默认不改样式。

> **注意**：这四条命令在 Mac 上也能跑，但文件占用、权限、盘符这几条
> 在 Mac 上只能证明代码不崩。**只有 Windows 上的结果算数**，
> `--platform-check` 会自己在输出里标注这一点。

## 二、带宏的真 `.xlsm`（清单第 8 项最后一条）

造不出合法的 `vbaProject.bin`，所以宏保留只能用真文件验。
找一个**带宏的** `.xlsm`（或在 Excel 里录一个空宏另存），然后：

```powershell
.\FileBatchTool.exe --platform-check --xlsm "C:\路径\带宏的文件.xlsm"
```

期望：`[通过] 真实宏文件的宏保留`。

如果失败，记下报错原文——这是**真实问题**，要修。

## 三、界面真机验证（清单第 1、4、9 项）

自动检查跑的是无头流程，下面这些要人眼看。

### 3.1 安装 / 启动

- [ ] 双击 `FileBatchTool.exe` 能启动，**不弹黑色命令行窗口**
- [ ] 任务栏和窗口左上角有图标
- [ ] 右键 exe →属性→详细信息：产品名称 `文件批量处理工具`、版本 `1.0.0`、
      公司名称**为空**（我们不编造公司信息）
- [ ] Defender / 杀软没有拦截或隔离（如果弹"未知发布者"是正常的，我们没有代码签名证书）
- [ ] 关掉窗口能正常退出，任务管理器里没有残留进程

### 3.2 Excel 工具箱六个标签逐项（清单第 4 项）

每一项都走完整流程：拖入文件 → 设参数 → 生成预览 → 开始执行 → 看日志。

| 标签 | 怎么试 | 看什么 |
|---|---|---|
| 合并 | 拖 2~3 个列顺序不同的 xlsx/csv | 按列名对齐，缺列补空 |
| 去重 | 一张有重复行的表，勾 2 个关键列 | 预览里报出重复行数；输出只留一条 |
| 两表对比 | 拖 3 个文件，用 A/B 下拉挑其中两个 | 四张工作表；试试「交换 A/B」；把正在用的文件移出清单，看下拉有没有跟着变 |
| 数据清洗 | 一张有空行、首尾空格、`001` 编号的表 | 空行没了、空格清了、**`001` 还是 `001`** |
| 批量拆表 | 按"部门"拆，其中一个值故意写成 `行政/后勤` | 文件名里的 `/` 被换掉，没有报错 |
| 格式统一 | 一张字体/对齐混排的 xlsx | **字体、字号、对齐默认全部不变**；表头加粗、有边框、列宽自适应 |

额外要看的：

- [ ] 执行过程中点「中断」：已完成的文件保留，剩下的标成"用户中断"
- [ ] **执行过程中直接关窗**：弹出"当前任务仍在执行，是否停止任务并退出？"，
      默认按钮是"继续执行"，选"停止任务并退出"后能安全退出
- [ ] 日志能保存成 txt，中文不乱码
- [ ] 「打开输出文件夹」能在资源管理器里打开正确位置

### 3.3 中文 / 空格 / 长路径（清单第 5 项，界面侧）

- [ ] 输出目录选一个**中文带空格**的路径，比如 `D:\我的 文档\处理结果`
- [ ] 输出目录选一个**很深**的路径，看预览里有没有出现"路径过长"的提示，
      提示是不是人话（不应出现 `WinError`、`Errno`）
- [ ] 输出目录选一个**不存在的盘符**（比如 `Z:\`），看错误提示是不是人话

### 3.4 DPI / 缩放（清单第 9 项）

在 设置 → 系统 → 显示 → 缩放 里依次切到 **100% / 125% / 150% / 175% / 200%**，
每次**重新启动**程序（Qt 的缩放在启动时读取）：

- [ ] 左侧导航文字不截断、不重叠
- [ ] Excel 工具箱六个标签都看得全
- [ ] 预览表格和日志面板没有被挤掉
- [ ] 按钮文字不溢出

CI 里也会跑 `check_dpi.py --exe`，产出 `Windows-DPI截图` artifact，
可以和肉眼结果对照。

### 3.5 文件占用（清单第 6 项，界面侧）

- [ ] 用 Excel **打开**一个源文件，然后在工具里处理它 →
      失败提示应该是"没有权限访问该文件，可能正在被 Excel 打开"这类人话
- [ ] 一个文件失败**不能**影响同批次其它文件
